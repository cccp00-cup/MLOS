安装方法

下载得到 .deb 后，任选一种方式安装（会自动装齐依赖）：

  1. 图形方式：双击 .deb → 在「软件商店 / Discover」里点安装，输入密码即可。
  2. 命令行（最稳）：
# 以程序坞为例；其它组件把文件名换成对应的即可
sudo apt install ./dock_26.9.25-1_amd64.deb

这是本地 .deb，没有 GPG 签名，安装时出现「不受信任 / 未签名」提示属正常， 确认继续即可。用 apt 安装比双击更可靠地处理依赖。

卸载：sudo apt remove dock （把 dock 换成 island / launchpad / topbar）。 其它发行版（Arch / Fedora / openSUSE…）请从各仓库源码构建。
